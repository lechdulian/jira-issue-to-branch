# jira-issue-to-branch
Chrome Extension to copy a JIRA issue title as a git feature branch name

## Installation 

1. Download the zip file from the release page
2. Extract the contents of the zip archive
3. In Chrome, navigate to `chrome://extensions/`
4. **Enable "Developer mode"** (toggle in the top-right corner)
5. Drag and drop the extracted folder anywhere onto the extensions page in Chrome

Optionally, in the extensions menu on the Chrome toolbar (puzzle icon), pin the extension to make it permanently visible next to the address bar.

## Usage
When on a JIRA issue page in the browser, click the extension icon. The converted feature branch name will be displayed in a popup. Click the feature branch name to copy it to the clipboard.
